# ตัวทดลอง — ไม่ใช่ส่วนหนึ่งของแอป

ไฟล์ในโฟลเดอร์นี้เป็นแบบจำลองไว้คุยกับเจ้าของร้านก่อนลงมือทำของจริง

- **ไม่ถูกรวมตอน build** — อยู่นอก `src/` และนอก `public/` `npm run build` ไม่แตะโฟลเดอร์นี้
- **ไม่ถูก deploy** — `deploy.cmd` อัปแค่ `dist/` ไฟล์พวกนี้ไม่ขึ้นเว็บ
- **ไม่ต่อฐานข้อมูล** — ไม่มี Firebase ไม่มีการบันทึกอะไรทั้งนั้น

## cost-lab.html

ทดลองวิธีคิดต้นทุนต่อไม้แบบ 3 ชั้น: วัตถุดิบหลัก · ของกึ่งสำเร็จ (น้ำจิ้ม) · ของจิปาถะเฉลี่ย
เปิดด้วยการดับเบิลคลิกได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต
